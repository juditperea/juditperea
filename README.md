# ✦ Featured Project

## Moodboard

A visual discovery and inspiration application built with **React, TypeScript, Tailwind CSS and the Pexels API**.

Moodboard allows users to discover visual references, search for images, save favorites and switch between different gallery layouts.

[![Moodboard demo](https://raw.githubusercontent.com/juditperea/portfolio_assets/main/moodboard-demo.gif)](https://moodboard-ashy-rho.vercel.app/)

### ✦ Features

- Infinite visual discovery feed
- Image search using the Pexels API
- Grid / Masonry / Feed layouts
- Persistent favorites
- Personal favorites page
- Image detail modal
- Light / Dark mode
- Responsive navigation
- Responsive image loading
- Persistent layout preferences
- Mobile-friendly interface
